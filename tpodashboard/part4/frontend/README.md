# Frontend (placeholder)

This directory is a reserved extension point for the future web dashboard.

Part 1 (Foundation) does not implement a frontend. The backend is fully
usable on its own through its versioned HTTP API — see `/docs` (Swagger UI)
and `/redoc` once the backend is running.

When the dashboard is built in a later part, it will live here and consume
the backend API defined in `backend/app/api/v1/`.
