### UI Designer — design · design/cse · product/general · fresher→
Designs visual interfaces and design systems.
**STACK** — Core (5): **visual design** (typography, color, layout, spacing, hierarchy, grids) · **UI patterns & components** (states, responsive, design systems) · **tools (Figma)** · interaction basics (micro-interactions, feedback) · accessibility (contrast, WCAG). Tools (3): Figma · design systems · prototyping. Emerging (2): design tokens · AI design tools · motion.
**ROUNDS** — portfolio → UI design exercise → critique → behavioral.
**ASKABLE** — *Portfolio:* `[M]` walk through a UI; your visual decisions (type/color/spacing); before/after. `[H]` defend a visual choice; consistency across a system. *Design exercise:* `[M]` design a screen/component for <flow>; build states (empty/loading/error/success); responsive behavior. `[H]` design a component library; complex layout. *Critique:* `[M]` critique this UI (hierarchy, contrast, spacing, consistency). `[H]` balance aesthetics vs usability. *Fundamentals:* `[E]` typographic hierarchy; color theory; whitespace. `[M]` grids; design systems; accessibility (contrast ratios).
**STRONG/WEAK** — Strong: strong visual craft + systems + accessibility + rationale. Weak: inconsistent, no system/accessibility, "looks nice" without reasoning. **RED FLAGS** — ignores states/accessibility; no design-system thinking.

### Interaction Designer — design · design/cse · product · fresher→
Designs how users interact with products (behavior, flows, motion).
**STACK** — Core (5): **interaction design** (flows, states, transitions, micro-interactions, feedback) · **prototyping** (Figma/ProtoPie, hi-fi interactive) · **UX fundamentals** (mental models, affordances, heuristics) · information architecture · usability. Tools (3): Figma/ProtoPie · prototyping · research. Emerging (2): motion/animation · voice/gesture UI · AI interactions.
**ROUNDS** — portfolio → interaction exercise → critique → behavioral.
**ASKABLE** — *Interaction:* `[E]` what is a micro-interaction; affordance. `[M]` design an interaction/flow for <task>; states + transitions; feedback/error handling; loading/empty states. `[H]` complex flow (multi-step, edge cases); design for delight vs efficiency. *Prototyping:* `[M]` prototype an interaction; when hi-fi vs lo-fi. *Fundamentals:* `[M]` mental models; Nielsen heuristics; reduce friction. `[H]` novel interaction patterns.
**STRONG/WEAK** — Strong: flow + state + feedback thinking, prototyping skill. Weak: static-screen mindset, ignores states/edges. **RED FLAGS** — no state/edge-case thinking.

### UX Researcher — design · design/any · product · fresher→
Studies users to inform design decisions.
**STACK** — Core (5): **research methods** (qualitative — interviews, usability tests, diary; quantitative — surveys, analytics) · **study design** (goals, participants, bias, sample) · **synthesis** (affinity mapping, personas, journey maps, insights) · statistics basics · communication of findings. Tools (3): research tools · survey/analytics · Figma. Emerging (2): mixed methods · AI-assisted research · continuous discovery.
**ROUNDS** — research case → methods depth → synthesis → behavioral.
**ASKABLE** — *Methods:* `[E]` qualitative vs quantitative; what is a usability test. `[M]` which method for <question>; interview vs survey vs test; write research questions; avoid leading questions; sample/recruiting. `[H]` mixed-method study; measure UX; longitudinal research. *Study design:* `[M]` design a study to answer <question>; bias sources + mitigation. `[H]` statistical rigor; generalizability. *Synthesis:* `[M]` affinity mapping; personas/journey maps; turn data into insights → recommendations. `[H]` conflicting findings; influencing product decisions.
**STRONG/WEAK** — Strong: right method for the question + rigorous + actionable insights. Weak: one method for everything, biased studies, no synthesis. **RED FLAGS** — leading questions; no bias awareness; can't turn research into decisions.

### Graphic / Visual / Motion Designer — design · design/any · general/product · fresher→
Visual communication / brand / motion graphics.
**STACK & QUESTIONS** —
- **Graphic/Visual Designer:** core: visual design (typography, color, composition, layout, branding), tools (Photoshop/Illustrator/Figma), design principles, brand systems. `[M]` portfolio walkthrough + rationale; design a poster/banner/brand asset; color/type choices; brand consistency; critique a design. `[H]` build a brand system; adapt across formats.
- **Motion Designer:** core: motion principles (timing, easing, anticipation), tools (After Effects/Lottie), storytelling, animation + visual design. `[M]` animate a UI element/logo; motion principles (easing/timing); when motion helps vs distracts. `[H]` complex motion sequence; performance (Lottie/optimized).
**STRONG/WEAK / RED FLAGS** — Strong: craft + principles + rationale + brand consistency. Red flag: no principles/rationale; inconsistent.
